# kavikehnachatehain
Kuch lafz kahe nahi jaate bas andar kahin zinda reh jaate hain  Yeh jagah unhi lafzon ka ghar hai jo dil mein rehkar bhi sukoon nahi lene dete  Yahan kavita likhi nahi jaati nikali jaati hai  Jo tum keh nahi paaye shayad kisi aur ne likh diya ho  Kavi Kehna Chahte Hain Ki  har dil mein ek kavita adhuri hai
